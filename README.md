# Programming
Лабораторные работы по ОАИП на C# и WPF.

## ЛР2. Редактор одного контакта
Откройте `src/Contacts/Contacts.sln` в Visual Studio. Для запуска нужны Windows и .NET 8 с поддержкой WPF.

В левой панели можно изменить имя, телефон и почту. Правая панель показывает значения после каждого ввода. **Save** записывает контакт в JSON, **Load** загружает его обратно. Путь по умолчанию — папка «Мои документы», файл `Contacts/contacts.json`.

Для сравнения этапов использован учебный пример [SH1NDEM/Contacts](https://github.com/SH1NDEM/Contacts/tree/fceac5f012af0ae26af90347682758f9a1e8c382). В архиве примера содержалась итоговая версия с тремя проектами. Эта ветка реализует задание № 2 с одним проектом View.

## ЛР3. Коллекция контактов
Список восстанавливается при запуске. Для новой записи нажмите **Add**, заполните поля и нажмите **Apply**. **Edit** работает с копией записи. Выбор другой записи отменяет правки. **Remove** выбирает следующий или последний оставшийся контакт. Для отдельного демонстрационного файла можно задать переменную `CONTACTS_JSON_PATH`.
